# 票 #23:`kd read` 丢弃正文配图（`html2text` 吞 `<img>`）

状态: 🔄 待实现(2026-09-17 实测确认) | 依赖:无（与票 #22 相互独立，可并行） | 优先级:P2
证据: `docs/research/2026-09-17-金蝶知识库配图链路实测.md`、`docs/research/2026-09-17-配图纳入回答的接入方案.md`

## 问题

`kd read` 返回的 `contentText` **不含任何图片信息**——图片 URL 在 HTML→文本转换中被整体销毁，且不留痕迹。

**实测证据**（目标文档 `646787188905978624`，《金蝶AIOpenAPI错误码说明》）：

| 层 | 长度 | `<img>` 数 |
|---|---|---|
| 上游 `content`（原始 HTML） | 24397 | **5** |
| `kd read` 的 `contentText` | 3393 | — |

对 `contentText` 做子串检查：`img` / `download` / `.png` **全部为 False**。

### 根因

`src/kd/_core_impl.py:305`（`html2text()` 内）：

```python
h = re.sub(r"<[^>]+>", "", h)
```

这个通配正则的本意是"剥掉剩余标签"。它**先**处理了 `</p>` / `<br>` / `</td>` 等结构性标签（转成换行/制表符），**再**执行这一行——于是 `<img src="...">` 作为"剩余标签"被整体删除，连 URL 都不留。

**这不是金蝶侧的问题**：上游 HTML 里 `<img>` 真实存在（见上表），是 `kd` 自己把它扔了。

### 影响范围

- **所有** `kd read` / `kd ask` 的正文都没有图。`ask` 共用同一个 `html2text()`。
- 金蝶文档的图**大量是操作截图**（界面路径指示），其信息在正文文本里常常缺失——这正是这类文档"看文字看不明白、一看图就懂"的原因。丢弃图片等于丢弃了这类文档的核心信息。
- 实测图密度不低：抽检两篇分别为 **5 图**（24397 字符）与 **7 图**（31963 字符）；另一轮抽样（见调研文档）称 6 篇均值 11.7 图/篇、最大 32 图。**图密度是这篇文档的信息主体之一，不是一个可以忽略的边缘字段。**

## 改动

**在 `html2text()` 里保留图片**，而不是把 URL 丢掉：

1. 在通配删标签**之前**，先把 `<img src="...">` 替换为一个可解析的占位标记（例如 `\n![img](<绝对URL>)\n` 或自定义 token）。
2. 处理两种 URL 形态并**归一化为绝对地址**：
   - 绝对：`https://vip.kingdee.com/download/xxx.png`
   - 相对：`/download/xxx.png` → 补 `https://vip.kingdee.com`
   - **双域名都要接受**：实测有图落在 `vip-admin.kingdee.com`
3. 保留**位置信息**（图出现在正文哪个位置），因为"这张截图在讲哪一步"依赖上下文。

**输出形态建议**：`kd read` / `kd ask` 的返回体新增 `images` 字段：

```
images: [
  { docId, index, url（绝对）, alt, anchor（邻近标题/前文片段）, offset }
]
```

**不要把图 URL 塞进 `contentText`**——那会污染现有的纯文本契约（`contentText` 是给 LLM 读的正文）。图片是**结构化附属信息**，应独立成字段。若需在正文里留占位，用明确标记并同步更新回归白名单。

⚠️ **形态决策需先定**（实现前确认）：`contentText` 内是否保留占位符。保留则 `t_read_*` / `t_ask_*` 的正文断言会变；不保留则图片与文字的位置关系只能靠 `offset` 表达。

## 验收

- `python3 src/kd_run.py read 646787188905978624` → 返回体含 `images` 字段，**5 条**，URL 均为绝对地址且可 `curl` 200。
- 抽检 7 图文档（`549952532701564672`）→ `images` 为 **7 条**。
- 相对路径的图被正确补全为绝对地址；`vip-admin.kingdee.com` 的图不被漏掉。
- `contentText` 的**文本内容不回归**（除约定的占位符外，与改动前一致）。
- 三件套全绿：
  ```bash
  python3 tests/kd_regression.py                 # 10/10, EXIT=0
  python3 scripts/check_core_surface.py          # 10 判据全 PASS, EXIT=0
  python3 tests/kd_regression.py --online        # 29/29, EXIT=0
  ```
- 若返回体新增 `images`，`READ_KEYS` / `SEARCH_KEYS` 等白名单同步（**注意 `check_no_extra` 禁多余键**）。

## 不做

- **不引入图像理解**。本票只把"图片 URL 与位置"这个信息**从被丢弃变为可用**。要不要读图内容、怎么读，是调用层的决策（见 `docs/research/2026-09-17-配图纳入回答的接入方案.md`）。
- **不加任何依赖**。纯正则 + 标准库。
- **不下载图片**。`kd` 不落盘的纪律不变；本票只暴露 URL。
