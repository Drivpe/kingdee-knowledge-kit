# ADR-0009:原句作为独立检索路参与 RRF 融合

日期:2026-09-16 | 状态:已采纳 | 关联:ADR-0005(三层检索路由)、私有仓 docs/research/2026-09-16-匿名搜索可达性归因链条.md

## 背景

`plan_routes()` 把问句拆成 ≤6 条片段路由(症状词路 / 字段名词路 / 产品词路),
原句只在 `raw` 兜底分支里使用——**触发条件是「什么都拆不出来」**,即最有信息量的一路被放在最不可能执行的位置。

2026-09-06 实测(私有仓归因链条 §2.1,连测三次复现):目标文档 `873372977646105600`

| 查询形态 | 排位 |
|---|---|
| 完整原句 + `productIds=93` + `sortsType=1` | **第 1** |
| 完整原句 + `productIds=93` + `sortsType=2` | 进不了前 50 |
| 5 条片段路由 RRF(k=60)融合后 | **第 23** |

系统取 top 4 深读 → 金牌文档出局。**融合不是问题**(目标在两路里各排 20/21,融合忠实反映上游排序),
问题是**原句从未参与**。

MMLF 论文(Findings of NAACL 2025)Table 3 已实测:原查询以独立一路参与融合
(RRF w/ q included 五集均值 **73.50**)优于不含原查询(**71.51**)与串接式(**71.92**)。

## 决策

1. **原句作为独立一路**(`kind: "raw:question"`),与各片段路由**同权重**参与 RRF 融合,
   而非并入某条扩展路。这不是兜底,是**常规路**。
   命名取 `raw:question` 而非 `symptom:raw`:它与兜底路 `raw`(仅在什么都拆不出时触发的 60 字截断路)
   语义不同——用 `raw:question` 前缀把"恒常参与的原句路"与"兜底路"在 `kind` 上直接区分开,
   调用方读 `routes[].kind` 时不必靠位置猜。
2. **该路固定 `sortsType=1`**(相关性排序)。依据:实测 `sortsType=0/1` → 第 1,`2/3` → 前 50 外。
   其余路保持各自既有 `sortsType` 不变,避免改变既有召回集合。
3. **路由上限由 ≤6 提到 ≤7**,原句路**保席位**(与产品词路同样处理,截断时不被挤掉)。
4. **上游预算上限相应提高**:`budget.maxUpstreamPerAsk` 由 16 调到 32。
   注意匿名链路虽无账号额度,但**预算机制仍保留**——它是防脚本失控的护栏,不是额度限制。
   补充实测(2026-09-16,本轮复核):8 例候选在 16 与 32 两档下逐例对照,**消耗完全相同(9-15 次)**,
   gold 存活与排位零差异。即**当前用例集根本没触到上限**,32 是"留足余量"而非"修复瓶颈"。
   本 ADR 原先把某次判定失败归因于"预算提前收尾"的因果说法已撤回。
5. **私有仓脚本口径同步修正**:`m-gold.py:98`、`m-harvest.py:84`、`m-probe.py:144` 三处硬编码的
   `sortsType=2` 统一改为 1。服务层本就是 `sorts_type=1`(正确),脚本层是错的——**服务对、脚本错**,
   该分裂须消除,否则脚本结论不能用来否决服务行为。
6. **`sortsType` 语义须写进文档**:`0/1` = 相关性排序,`2/3` = 时间倒序(新→旧)。
   时间倒序对「老文档被编辑」与「长尾低流量文档」是结构性盲区——这正是 ADR-0005 记录的原始事故根因之一。

## 后果

- 单次 ask 上游搜索请求 +1(7 路),预算上限提高;延迟略增;
- 原句路的 `sortsType=1` 使该路召回集合与其余路不同分布——这是**有意为之**(引入排序多样性);
- 该改动是**单点收益**的性质:它能救回"原句排第 1 而片段融合排 23"这类用例,
  但不改变上游排序本身的限制。真正的通用机制(第一轮失败判定 + 第二轮词汇桥接)不在本 ADR 范围。

## 备选与取舍

- **挤掉最弱一路保持 ≤6**:被否——原句路与片段路信息独立,不该互相挤占;
- **全部路统一改 `sortsType=1`**:暂否——会改变所有路既有召回集合,影响面超出本 ADR 的可验证范围,
  待原句路单独测得有效后再评估;
- **不加路,只把 `raw` 改为恒定触发**:被否——`raw` 带 60 字截断语义,复用它会引入隐含行为耦合。
