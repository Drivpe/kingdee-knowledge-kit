> **状态**：本文件**推翻 `docs/research/2026-09-18-链接可访问性矩阵.md` 的部分口径**。

## 0. 一句话

**数据全在、接口正常，但网页路径已整体不再对外提供。** 「在回答里贴能点开的链接」这一目标，
在当前上游条件下**做不到**——这不是内核缺陷，是上游不再给网页入口。

## 1. 决定性证据：同一内容，接口通、网页死

```
# 1) 内核匿名链路，完整走通（零账号、零 cookie）
$ python3 src/kd_run.py search "单据转换" --product 93 --size 3
  → total=1032，条目《什么是单据转换？》id=6226

$ python3 src/kd_run.py read 6226 --kind knowledge
  → contentText 完整（187 字，含 BOTP 平台说明）

# 2) 同一个 id 的网页路径（内核自己产出的 url 字段）
$ 首跳 https://vip.kingdee.com/knowledge/6226   → 302 → Location: /error/404
$ 跟随重定向                                     → final_url = https://vip.kingdee.com/error/404
$ 人看到的是                                     → 404 错误页（title 是站点默认标题）

# 3) 同一 id 的接口路径（内核 read 真实使用的端点）
$ https://vip.kingdee.com/knowledgeapi/knowledge/6226
  → 200，title='什么是单据转换？'，正文长度 224  ← 完全正常
```

**结论**：`search`/`read`（接口）与"人点开链接"（网页）是**两条独立的路**。
前者通，后者已被上游关闭。

## 2. 失效率抽样（干净对照，排除限流假象）

### 2.1 类目与可点性**无关**——这是对 09-18 口径的修正

09-18 矩阵文档称「`knowledge/` 30/30 可贴」。本轮实测该结论**已过期**：

| 样本来源 | 实测结果 |
|---|---|
| 文档记载「4/4 稳定 200」的 `225574219084759552` | 现 **302 → /error/404**（5 次重复，4 次 302） |
| 文档记载「可贴」的 `636272302971087872` | 现 **302 → /error/404**（5 次重复，5 次 302） |
| 本轮全新、从未请求过的条目（5 条） | **全部 302 → /error/404** |

### 2.2 排除了"被限流"这一解释

曾观测到一次 `200,200,302,302,302` 的**顺序退化**，故必须排除风控伪影。判别实验：

| 检查项 | 结果 | 结论 |
|---|---|---|
| 搜索 API 是否仍正常 | `total=16101`，正常返回 | **IP 未被封** |
| 静默 240 s 后**冷启动单发** | 仍 302 | 不是"请求过密" |
| 换 UA（Chrome / curl / Googlebot） | 均 302 | 不是 UA 分流 |
| 带站内 Referer | 仍 302 | 不是来源校验 |
| 站点首页本身 | 恒 200 | 不是全站故障 |
| 全新未请求过的 id | 仍 302 | 不是历史性因素 |

故那两次 `200` 判定为**限速窗口内的短暂放行**，不代表页面真实状态。

### 2.3 `article/` 同样整体失效

抽测 `article/829644300227958016`、`...370955304144117760`、`...239776518421883648`
→ **3/3 全部 302 → /error/404**。

### 2.4 `answer` 的失效是**路径级必然**，不是个案

对**真实存在**的问答帖（`qid=281104761569181440`，`isAdopt=true`）逐一试探：

| 候选路径 | 首跳 |
|---|---|
| `question/<qid>`（单数，内核现用） | 302 → `/error/404` |
| `questions/<qid>`（复数） | 302 → `/error/404?lang=en-US` |
| `answer/<qid>` / `q/<qid>` / `topic/<qid>` / `bbs/<qid>` | 全部 302 → `/error/404` |
| `api/questions/<qid>` | 200（是接口，不是网页） |

另：帖子详情 JSON 里的 `entityUrl` 字段实测为 `None`；20 个帖子的 `knowledgeId` 均为 `0`
（无"已转知识文档"的替代形态）。
**故 `answer` 条目没有任何可点的网页链接**，这是常量而非需逐条判断的事。

## 4. 新发现：上游条目自带 `productLineId`（与请求参数不同值域）

### 4.1 事实

上游搜索返回的**每条原始条目**都带一个 `productLineId` 字段——这是**条目自身的产品线归属**。
当前 `_norm_item` 把它整个丢弃了。

**两套编号不是同一个空间**（这是 `2`/`3` 难以判定的根因）：

| 请求侧 | 观测值域 | 含义 |
|---|---|---|
| `productIds[0]`（URL 参数） | `0/1/2/3/9/10/11/16/17/24/28/87/93` | 过滤开关 |
| `productLineId`（条目字段） | `1/2/7/8/9/10/11/12/29/35/40` | 条目真实归属 |

对照实例：请求 `pid=87` 返回的条目 `productLineId=29`；请求 `pid=2` 返回的条目 `productLineId=1`。

### 4.2 未记录 ID `2`/`3` 的实测性质

| `--product` | total（词=单据转换） | 条目性质 |
|---|---|---|
| `2` | 611 | **全部是 `Answer`**，`productLineId=1`（星空侧）。标题：「插件开发调试」「简单账表如何进行分页」「报表插件开发按钮,可联查单据」→ **星空侧二开问答专区** |
| `3` | 1023 | 类目含 `金蝶AI苍穹` + **`金蝶AI星瀚`** + `金蝶AI套件`，`productLineId` 为 `29`(苍穹) 与 `2`(星瀚) → **比 87 宽** |
| `87` | 785 | 类目纯苍穹系（无星瀚） |
| `93` | 1032 | 星空旗舰版（默认） |

词「插件开发」下 **87 与 3 的交集仅 6/20**（各 14 条互不相同），证明二者非同源。

### 4.3 其他实测

- `productIds[0]` + `productIds[1]` **多值可用**：87+93 → total=1007（单 87=785、单 93=1032）。
- 值域地图（词=单据转换，size=10）：`4-8`、`12`、`14-15`、`18-23`、`25-27`、`29-30` 为 0；
  `9`=24、`10`=302、`11`=1935、`13`=5、`16`=10、`17`=19、`24`=15、`28`=2。
- `_DETAIL_WORKERS` 同族的假 seam：`_config.py` 的 `_Budget` docstring 声称"深读路径经
  `ThreadPoolExecutor` 并发进入"，但全仓 `grep ThreadPoolExecutor|concurrent` **只有这一句注释**，
  无 import、无线程池。`threading.Lock` 真实存在（3 处），但归因理由是编的。

### 4.4 未决

`productLineId` 是否应作为可执行的产品线判据对外暴露（它是整数、值域独立、上游直给），
本轮**未改代码**，仅记录。若要用，需同步 16 键白名单 + ANSWER-SPEC 第 8 条 + 守卫。

## 5. 复现命令

```bash
cd /mnt/d/03_Work/03_Develop/kingdee-knowledge-kit

# 匿名链路通（接口）
python3 src/kd_run.py search "单据转换" --product 93 --size 3
python3 src/kd_run.py read 6226 --kind knowledge

# 网页路径死（同一个 url）
python3 - <<'PY'
import urllib.request, urllib.error
class NoR(urllib.request.HTTPRedirectHandler):
    def redirect_request(self,*a,**k): return None
op=urllib.request.build_opener(NoR)
req=urllib.request.Request("https://vip.kingdee.com/knowledge/6226",
                           headers={"User-Agent":"Mozilla/5.0"})
try:
    op.open(req, timeout=20)
except urllib.error.HTTPError as e:
    print("首跳", e.code, "→", e.headers.get("Location"))   # 302 → /error/404
PY
```

⚠️ **探测纪律**：匿名链路交互档 2–3 请求/秒 + 抖动，禁止高频连打（封禁=免费链路死亡）。
本文件所有对照实验均以 ≥1.2 s 间隔、部分以 3.5 s 间隔完成。
