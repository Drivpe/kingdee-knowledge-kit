## 3. 差距量化(kd v4.0 vs 官方,2026-09-06 评测)

| 维度 | 官方 | kd v4.0 | 差距性质 |
|---|---|---|---|
| usage 层(12 例正式金标) | — | recall@5=0.756 / @10=0.800 / MRR=0.628 | 剩余 ~20-25% 缺口主要是**语义匹配**(向量召回的对口地盘) |
| reference 层(14 例官方金标) | 100%(定义如此) | recall@5=0.120 | **语料/访问面差距**:官方索引含课程、发版说明、产品文档,匿名关键词检索不可达——非纯算法差距 |
| chunk 引用 | `[chunk#N]` | `[n](chunk#m)`(标题感知切片) | 粒度对齐;选段方式=关键词得分 vs 语义得分 |
| 追问澄清 | clarification 协议 | 无(agent 侧可人工补) | 可低成本补齐 |
| 语料范围 | 官方全量语义索引 | 社区三实体+缓存自增长 | 匿名侧结构性限制 |
| 成本/依赖 | 登录+身份认证 | 零账号/零点数 | kd 反超 |
| 深读 | recallDocuments 仅摘要 | 全文+追问链+并行深读 | kd 反超 |
| 暖查询 | 每次打后端 | **p50≈14ms**(缓存) | kd 反超 |

**一句话**:正式使用口径下差距 ≈「两成的语义召回缺口」;对官方金标的 88% 不可达主要是语料墙,不是算法墙。

## 4. 改进点清单(按 ROI 排序,全部过评测门)

1. **向量召回二期**(最大缺口对口服地):chunks 表已预留 embedding BLOB;通道三选——本机 bge-small-zh-v1.5/bge-m3(需装 torch,~1-2GB)、sqlite-vec 扩展、免费 embedding API(触红线,弃)。检索=FTS5+向量 RRF 混合。**门槛:usage 层 recall@5 必须显著 >0.756 才转正**。
2. **重排复活(依赖 #1)**:向量分数到位后,重排才有语义依据(上次失败=纯手工信号);可选 bge-reranker-v2-m3 本地或 4090 LLM listwise 重排。
3. **查询改写 LLM 化**:kd ai 关键词规划已有 LLM 通道,可加 step-back/HyDE 变体应对冷难问题——同义词教训在前,**评测证明再开**。
4. **追问澄清等价物**(零代码):SKILL.md 加一条——ask 包低置信/歧义时,agent 先向用户提一个澄清问题(模仿官方 clarification,官方协议见交接文档 6)。
5. **语料预热**:后台低频把用户高频域文档灌入缓存语料库(local=1 即可用),严守人类频率。
6. **usage 评测层持续生长**:每次真实解题会话沉淀「问题+解题文档」,按域分桶报表;这同时是 #1 的验收基线。
7. **知识图谱(远期)**:官方 KG 混合召回;kd 可先做轻量元数据路由(产品线/模块/实体类型),全量 KG 的 ROI 在向量之后。

## 6. 增补:语料墙的实证分解(2026-09-06 晚)

对 reference 层 76 篇去重金标抽样 10 篇做「按 ID 读 × 按标题搜」双测:

| 测试 | 结果 |
|---|---|
| 按 ID 读全文(knowledgeapi) | **10/10 可读** —— 金标全在社区库内,访问层无墙 |
| 按标题搜索(自己标题前 12 字,top-50) | **0/10 搜得到** —— 社区搜索索引不覆盖这批文档 |
| 决定性深扫:「一键追溯」8363 条结果深翻 500 条(sortsType=2 时间序) | 目标金标未命中 —— 是**索引覆盖缺口**,不是排序问题 |
| sortsType 探测 | **sortsType=2 = 时间倒序**(增量枚举口子);3=有用度,1/4=综合 |
| ID 邻域带扫描(雪花 ID ±6) | 0/13 —— 知识/问答/文章各有独立端点,逐 ID 盲扫成本过高,弃 |

**结论:差距 = 发现层索引覆盖缺口,不是信源缺失、不是排序调优问题。** 弥补路径(全部喂同一个「原链接+语义」本地索引):
1. **推荐图谱游走(最对症)**:文章详情页带 recommendArray(每篇约 10 篇相关文章含摘要,交接文档 6 §2.6 已验证可解析);从 usage 种子 BFS 游走——官方金标高度呈"相关问题簇"分布,图游走天然命中其邻域;
2. **sortsType=2 时间网格增量**:领域词表每日时间序扫一遍,覆盖索引内新/更新文档;
3. **官方 recallDocuments 采样**(现有流程扩展,分享链匿名可读;登录态 ai-search 可规模化但触账号红线,用户拍板);
4. **分类目录页 SSR 解析**(待探测:知识分类页 Nuxt 数据)。
