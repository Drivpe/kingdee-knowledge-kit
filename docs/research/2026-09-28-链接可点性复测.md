> **执行者**:本轮 Lead(独立完成)
> **上游**:`https://vip.kingdee.com`(匿名、零 cookie、零账号,与内核同链路)
> **纪律**:仅 HTTP GET 读取;请求间隔 1.2 s 且**每样本 2 次请求**(首跳 + 跟随),无并发;未写任何上游数据。
> **样本来源**:内核 `kd search` 真实产出的条目(非人工挑选),覆盖 knowledge / article / question 三档。
> **判定口径**:**跟随重定向看最终 URL(`url_effective`)**。落到 `/error/404` 判死,其余判活。

## 2. 为什么 09-27 会得出"一律 302"

**根因是判定方法,不是上游变化。** 09-27 那次结论建立在两类观测上:

1. **限速放行窗口被读成常态**——09-27 文档自己记录了 `200,200,302,302,302` 的
   顺序退化,并把它归因为"短暂放行";本轮在同样间隔(1.2 s)下重跑同类样本,
   得到的是**稳定的 200**。即那个"退化"更像是**当时触发了限流**,而结论却把
   限流期的表现推广成了路径级常量。
2. **只看首跳状态码**——`article/248777993676668672` 首跳 302,于是被判"失效";
   跟随重定向后它其实**迁移到了一个新的知识文档**(见 §3.2)。

⚠️ **教训(与开工清单第 4 条同型,这是第二次)**:判定可点性必须跟随重定向,
且**必须先排除限流**。单次观测 + 只看状态码 = 两次误判都发生了。

## 3. 两个方向的误判(都已实测坐实)

### 3.1 只看状态码会把**失效**判成**可点**

`question/` 的最终状态码恰为 **200**(成功重定向到 404 页)——只看状态码会误判。

### 3.2 只看首跳状态码会把**可点**判成**失效**

```
首跳 https://vip.kingdee.com/article/248777993676668672
  → 302, Location: /knowledge/248777993710223104
跟随 →
  → 200, url_effective = https://vip.kingdee.com/knowledge/248777993710223104
```

这是**上游把社区文章迁移成了知识文档**,旧 id 保留为跳转入口。它不是失效样本,
而是一份**活的**链接。09-18 与 09-27 两份文档都把它列为"稳定失效反例",
**两份都错在同一处**:只读首跳状态码。

**接口侧的两半对照**(补测,解释为什么旧文档会同时记下"失效"与"全空壳"):

| 侧 | 实测 |
|---|---|
| 网页(旧 id) | 302 → `/knowledge/248777993710223104`,跟随重定向后 **200 可点** |
| 接口(旧 id) | `title=None`、`contentText` 长度 **0** ← 原文档记的"全空壳" |
| 接口(迁移后 id) | `title='管理中心库维护页面安全加固'`、正文 **2187 字** |

即:旧 article id 在**网页侧活着**(跳转入口)、在**接口侧只给空壳**(内容已搬到新 id)。
旧文档把这两件事写成了一条结论("该条失效"),真相是**迁移**——这也是"网页路由与接口
是两条独立的路"这条总纲的又一个实例。

## 4. 政策结论(唯一真源 = `src/kd/contract.json` 的 `linkPolicy`)

| kind | 政策 | 依据 |
|---|---|---|
| `knowledge/` | **给链接** | 14/14 可点 |
| `article/` | **给链接** | 12/12 可点 |
| `question/` | **不给链接**,只给标题与出处 | 匿名 9/9 不可点 + 用户登录态 1 条不可点,**方向一致** |

**不做逐条可点性预判**:匿名判定会对登录态用户产生**假阴性**(用户登录态实测 6 条中
2 条匿名 302 而登录侧可点)。⚠️ 该样本仅 6 条,**不足以断言"登录态下全部可点"**——
故政策只声明"给链接",**不声明"保证可点"**。

## 5. 复现

```bash
cd /mnt/d/03_Work/03_Develop/kingdee-knowledge-kit
# 用内核真实产出的条目做样本,再逐条按 url_effective 判定
python3 - <<'PY'
import sys, time, urllib.request
sys.path.insert(0, "src")
from kd import core
r = core.search("单据转换", product_id=93)
for it in (r["results"] or [])[:5]:
    if it["type"] == "question":
        continue
    with urllib.request.urlopen(urllib.request.Request(
            it["url"], headers={"User-Agent": "Mozilla/5.0"}), timeout=20) as resp:
        print(it["type"], it["id"], resp.status, resp.url)  # 看最终 url
    time.sleep(1.2)
PY
```

⚠️ 探测纪律:匿名链路交互档 2–3 请求/秒 + 抖动,禁止高频连打(封禁 = 免费链路死亡)。
本轮全部对照实验以 ≥1.2 s 间隔、无并发完成。
